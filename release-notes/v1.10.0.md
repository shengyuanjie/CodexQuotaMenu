# v1.10.0 — 默认速度开关与重启提示 / Default Speed and Restart Options

## 中文

- 在“默认模型…”中新增“开启 1.5 倍速度（Fast）”选项，显示当前实际状态，并根据模型支持情况启用或禁用。
- 将速度选项与模型、推理强度一同保存并回读核验；识别系统层速度覆盖，在必要时通过 macOS 管理员验证同步更新已有覆盖。
- 保存并核验成功后，弹窗提供“现在重启 Codex”和“稍后手动重启”；回车默认选择稍后重启。
- 立即重启前提醒可能中断正在运行的任务；请求 Codex 正常退出，等待退出完成后重新打开同一应用。退出拒绝或超时会提示手动处理，不强制结束进程。
- 刷新和保存失败不弹出重启提示；选择稍后重启或自动重启失败均保留已保存设置。

实际提速取决于模型和服务状态，Fast 模式可能增加用量消耗。macOS 14+，Build 42。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Add “Enable 1.5× speed (Fast)” to Default Model settings, show the effective state, and enable the option according to model support.
- Save and verify speed together with model and reasoning effort. Detect managed speed defaults and update an existing local override with macOS administrator authentication when necessary.
- After saving and verification succeed, offer “Restart Codex Now” and “Restart Manually Later”. Return defaults to restarting later.
- Warn that restarting can interrupt running tasks. Request a normal quit, wait for completion, and reopen the same application. Report a refused or timed-out quit without force-quitting.
- Refreshes and failed saves do not prompt for restart. Deferring restart or a restart failure preserves saved settings.

Actual speed depends on the model and service conditions; Fast mode may consume more usage. macOS 14+, Build 42. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
