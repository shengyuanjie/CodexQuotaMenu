# v1.9.0 — 定时消息附件 / Scheduled Message Attachments

## 中文

- 定时发送消息支持添加文件和照片，统一使用“添加文件…”按钮，可多选、查看列表及移除附件。
- 支持只发送附件；最多 20 个附件，单个不超过 25 MB，总计不超过 100 MB。
- 安排时保存附件副本，移动或删除原文件不会影响已安排的消息；发送前校验副本完整性。
- 照片使用 Codex 图片输入；HEIC、TIFF 等格式转换为 JPEG 副本。普通文件通过本地路径供目标任务读取。
- 发送时间的加减按钮统一尺寸；消息编辑区默认显示约五行。
- 仅支持发送到已有 Codex 任务。移除本地测试版的“新建任务”功能和工作目录输入；旧测试记录仍可查看及取消，但不会再执行创建或发送。
- 继续使用 macOS LaunchAgent，不创建 Codex 内置定时任务，不更改默认模型或激活时间。

### 安装与验证

- macOS 14+，Build 37；同时提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件。
- 本机回归测试：292 项、0 失败、1 项因环境限制跳过；两种架构的 Release 构建通过。
- 用户已验证真实的文件及照片定时投递成功。已有任务的目标 ID、模型、推理强度和一次性投递逻辑保留。
- 附件副本随消息记录保留，移除记录时一起删除；普通文件读取仍受目标任务的文件权限约束。
- 启用 Hardened Runtime，使用 ad-hoc 签名，未经 Apple 公证。

## English

- Attach files and photos to one-time scheduled messages using a single **Add files…** button, with multiple selection and removal.
- Send attachments without an entered message; up to 20 files, 25 MB each and 100 MB total.
- Save copies when scheduling and check integrity before delivery. Moving or deleting originals does not affect saved copies.
- Send photos as Codex image inputs; convert formats such as HEIC and TIFF to JPEG copies. Reference ordinary files by local path for the target chat to read.
- Give all time-adjustment buttons consistent dimensions and default the message editor to approximately five lines.
- Target existing chats only. Remove new-chat creation and the working-directory field from the local preview. Old preview records remain visible and removable but cannot create chats or send messages.
- Keep macOS LaunchAgent scheduling, global defaults and activation times unchanged.

macOS 14+, Build 37. Apple Silicon and Intel archives include SHA-256 files. Local regression: 292 tests, zero failures, one environment-related skip; both Release builds passed. Real scheduled file and photo delivery was verified by the user. Copies remain until their message record is removed; ordinary-file reads remain subject to the target chat's permissions. Hardened Runtime with ad-hoc signing, without Apple notarization.
