# v1.10.4 — 修正激活设置窗口外观 / Fix Activation Settings Appearance

## 中文

- 统一激活时间设置窗口与滚动列表的背景，消除深色模式下内部深色矩形的色差，并沿用系统外观。
- 修正滚动内容的顶部对齐；标题和时间列表始终从顶部排列，窗口放大后不再在内容上方留下大块空白。
- 保留窗口缩放与长列表滚动，原有激活时间、启用状态和同步逻辑不变。
- 添加 `--activation-settings` 启动参数，可直接打开激活设置窗口。
- 增加中英文、浅色与深色、多个窗口尺寸下的顶部对齐回归检查。

本次无需更新 iPhone Scriptable 脚本。macOS 14+，Build 46。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Make the activation settings scroll area transparent so it shares the window background and follows the system appearance.
- Keep the heading and time list aligned to the top, removing the large gap above the content when resizing the window.
- Preserve window resizing, long-list scrolling, existing schedules, enabled states, and synchronization behavior.
- Add `--activation-settings` to open the activation settings window directly.
- Add top-alignment regression coverage for both languages, light and dark appearances, and multiple window sizes.

No iPhone Scriptable update is required. macOS 14+, Build 46. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
