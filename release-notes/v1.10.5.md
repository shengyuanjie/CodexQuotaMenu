# v1.10.5 — 重置卡与菜单可读性 / Reset Cards and Menu Readability

## 中文

- 下拉菜单新增重置卡可用数量与到期时间，使用 Codex 官方账户接口的数据；数据不可用或详情不完整时明确提示。
- 检测到新重置卡到账后，结束当前高概率周期的“冲冲冲”提示，恢复正常额度倒计时；发卡不等于额度已经恢复。
- 启动后首次成功读取只建立基线，不把已有重置卡误判为新到账；不自动使用重置卡。
- 改善下拉菜单可读性：只读信息使用系统次要文字色，功能项保持正文色，避免原先禁用菜单项文字过淡，同时区分数据和操作。
- 重置卡详情与已见卡片标识只保存在本次运行的进程内存，不加入菜单栏或 iPhone 小组件。

本次无需更新 iPhone Scriptable 脚本。macOS 14+，Build 47。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Show available reset-card counts and expiration dates in the dropdown, using Codex account data; explicitly indicate unavailable or incomplete details.
- Dismiss the current high-probability encouragement cycle when a new reset card arrives, restoring the normal quota countdown. Receiving a card does not mean quota has refilled.
- Establish a session baseline on the first successful query so cards already present at launch are not reported as new. Cards are never redeemed automatically.
- Improve menu readability with system secondary text for read-only information and normal text for actions, avoiding faint disabled-item labels while distinguishing information from controls.
- Keep reset-card details and seen identifiers only in app-process memory. Card counts are not added to the menu bar or iPhone widget.

No iPhone Scriptable update is required. macOS 14+, Build 47. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
