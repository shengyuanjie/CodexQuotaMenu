## 中文

### 本版本改进

- 修复长时间、多轮次任务继续执行时，菜单栏可能少计一个正在运行任务的问题。
- 任务日志现在按 JSONL 事件结构识别 `task_started` 和 `task_complete`，不再仅依赖固定大小日志末尾中的文字标志。
- 保留异常中断任务超过 30 分钟不再计入运行中的规则。

## English

### Improvements

- Fixed an issue where long-running, multi-turn tasks could be missing from the active-task count while continuing automatically.
- Task logs now use structured JSONL lifecycle events to distinguish `task_started` from `task_complete`, instead of relying only on text markers in a fixed-size log tail.
- Interrupted tasks that receive no updates for more than 30 minutes are still excluded from the active count.
