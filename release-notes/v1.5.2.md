## 中文

### 本版本改进

- 移除菜单栏和下拉菜单中的 `⏸` 等待操作状态。
- 移除对回复文字、待批准操作和用户意图的本地判断，避免等待状态误判。
- 菜单栏现在只显示 `▶` 活动任务数量；Codex 仍标记为 active 的任务统一计入其中。
- 保留剩余用量、重置倒计时、异常提示、中英文界面和语言切换功能。

## English

### Improvements

- Removed the `⏸` waiting-for-action state from the menu bar and drop-down menu.
- Removed local classification of response text, pending approvals, and user intent to prevent false waiting-state detections.
- The menu bar now shows only the `▶` active-task count; every task still marked active by Codex is included.
- Remaining usage, reset countdowns, error indicators, the bilingual interface, and language switching remain unchanged.
