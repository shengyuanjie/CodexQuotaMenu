# v1.10.8 — 定时发送新对话与粘贴修复 / New Scheduled Chats and Paste Fix

## 中文

- 定时发送的目标选框新增“新任务对话”，支持到点创建对话并使用所选模型、推理强度发送消息及附件。
- 默认采用 `~/Documents/Codex/日期/对话目录`，创建 `work`、`outputs` 子目录并自动避开同名目录；也可手动选择工作目录。
- 保存创建后的任务 ID，失败或中断不自动重试创建；旧版已停用的预览记录保持停用。
- 修复任务 ID 输入框无法使用 Command+V 的问题，同时支持全选、复制、剪切、撤销和重做。

macOS 14+，Build 50。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。已有激活时间与 iPhone Scriptable 脚本无需修改。

## English

- Adds **New chat** as a scheduled-message target, creating a chat at delivery time with the selected model, reasoning effort, message, and attachments.
- Uses `~/Documents/Codex/date/chat-folder` by default, with `work` and `outputs` subfolders and collision-safe numbered names. Custom working directories remain available.
- Saves the created chat ID and never automatically retries creation after failure or interruption. Disabled legacy preview records remain disabled.
- Fixes Command+V in the chat ID field and supports select all, copy, cut, undo, and redo.

macOS 14+, Build 50. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization. Existing activation times and the iPhone Scriptable widget require no changes.
