## 中文

### 本版本改进

- 新增“激活时间设置”，可自定义每天任意多个 Codex 用量窗口激活时间。
- “应用到 Codex”会直接创建或更新对应的后台计划任务，不再需要复制、粘贴或确认发送。
- 设置窗口自动检测实际计划任务状态；正常情况下隐藏刷新按钮，只在读取失败时显示“重试检测”。
- 同步仅管理完整名称严格匹配 `CodexQuotaMenu · HH:mm` 的任务，不会改动其他计划任务。
- 写入前会暂存并验证完整目标配置；同步失败时尝试恢复原有受管任务。
- 后台激活请求保持静默，任务失败时才由 Codex 提示。

## English

### Improvements

- Adds **Activation Times** for configuring any number of daily Codex usage-window activation times.
- **Apply to Codex** now creates or updates the matching background automations directly, without copying, pasting, or send confirmation.
- The settings window checks actual automation state automatically. Refresh is hidden during normal operation, while **Retry Check** appears after a read failure.
- Synchronization manages only tasks whose complete names exactly match `CodexQuotaMenu · HH:mm`; all other automations remain untouched.
- The app stages and validates the complete target configuration before replacement and attempts to restore the previous managed tasks if synchronization fails.
- Successful activation runs remain silent; Codex notifies only when a task fails.
