# v1.10.3 — 每日激活沿用默认模型 / Daily Activation Uses Current Defaults

## 中文

- 每日自动激活不再固定使用某个模型版本，改为每次执行时读取用户当前的实际默认模型，同时沿用推理强度和速度设置，包含系统托管覆盖。
- 更换默认模型后，下一次自动激活即可跟随，无需重新设置激活时间。
- 兼容旧版应用后台入口的调度参数；旧调度仍可执行，并使用当前默认值。可在“激活时间设置…”中点击“应用到 Codex”更新调度配置。
- 默认配置读取失败或所选模型不可用时，记录 `default_model_unavailable`，不会静默回退到固定旧模型。
- 保留临时会话、只读沙箱、激活结果核验和脱敏诊断，并更新中英文使用说明。

本次无需更新 iPhone Scriptable 脚本。自动激活仍需要 Mac 开机、系统处于唤醒状态，并具备网络及有效的 Codex 登录。

macOS 14+，Build 45。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Daily activation now reads the effective default model at execution time instead of pinning a model version. Reasoning effort and speed tier follow the current defaults, including managed overrides.
- Changes to the default model apply to the next activation without rescheduling.
- Preserve compatibility with older headless runner arguments; existing schedules use current defaults. Use “Apply to Codex” in activation settings to update the stored schedule configuration.
- Unreadable defaults or an unavailable selection produce `default_model_unavailable`, without silently falling back to a fixed older model.
- Retain ephemeral sessions, the read-only sandbox, activation verification, and redacted diagnostics; update the usage documentation.

No iPhone Scriptable update is required for this release. Activation still requires an awake Mac, network access, and a valid Codex login.

macOS 14+, Build 45. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
