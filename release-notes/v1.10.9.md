# v1.10.9 — 修复定时新对话不可见 / Scheduled Chat Visibility Fix

## 中文

- 修复定时新对话显示已发送、却无法在 Codex 默认任务列表找到的问题。新对话改由本机 app-server 创建并在同一交互会话发送，不再直接创建 `exec` 会话。
- 分开显示回合完成和普通聊天侧栏登记状态；缺少登记时显示“已发送，侧栏未登记”，并提供“打开任务”。当前不自动补写 Codex 的侧栏登记。
- 创建后的任务 ID 在发送前保存；审批阻塞、失败、中断或可见性未通过时不自动重发。

macOS 14+，Build 52。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Fixes scheduled new chats being marked sent but missing from the default Codex chat list. Creation and delivery now share a native local app-server session instead of creating a noninteractive `exec` session.
- Separates delivery completion from desktop Chats registration. Unregistered chats show “Sent; not in Chats” and can be opened from their record. Automatic desktop Chats registration is not currently supported.
- Saves the chat ID before delivery and never automatically resends after an approval block, failure, interruption, or unverified visibility.

macOS 14+, Build 52. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
