# v1.7.0 — 默认模型设置与后台可靠性 / Default Model Settings and Background Reliability

## 中文

### 新功能：默认模型…

- 在菜单栏直接选择以后新建会话的默认模型和推理强度；选项从本机 Codex 实时读取，并按模型支持范围展示。
- 显示后端实际默认值，识别用户配置与系统/托管覆盖的差异，避免只改用户配置却不生效。
- “保存并核验”更新用户配置后，启动新的查询后端回读验证。必要的本机系统修改由 macOS 管理员验证授权，仅修改模型相关字段并备份原文件。
- 拒绝不支持的配置格式、配置方案和无法确认来源的托管覆盖；取消授权、保存失败和核验不一致都有明确反馈。
- 支持中英文界面。已有会话、每日激活计划及激活专用模型保持不变；桌面端如保留旧缓存，请等任务结束后重启 Codex。

### 后台激活修复

- 每次执行重新定位 Codex CLI，并兼容新版桌面应用内的 CLI 路径，避免应用更新后旧路径失效。
- 校验结构化回合完成事件、非零输出和两次用量查询，不再将进程成功退出直接当成窗口已激活。
- 旧窗口临近到期时等待后补试；短暂失败有一次有界重试。保留按次脱敏诊断，区分已激活、旧窗口仍有效和无法验证。
- 不再通过删除文件“停用”旧内置自动化。请在 Codex 中暂停旧的 CodexQuotaMenu 定时任务；应用保留暂停记录并检测冲突，防止误报迁移成功。

### iPhone 小组件恢复改进

- 已读取的访问令牌仅在应用内存缓存，减少锁屏后 Keychain 暂不可用引发的误报 401；令牌暂不可用返回 503。
- Mac 启动、唤醒和用户会话恢复后会尝试恢复手机接口，保留用户的启用选择。
- Scriptable 对短暂的 401/503 重试一次，仍失败时使用有效期内的缓存。Mac 关机、睡眠或未运行服务时无法提供实时数据。

### 安装与升级

- 同时提供 Apple Silicon（arm64）和 Intel（x86_64）ZIP 及 SHA-256 校验文件；要求 macOS 14+。
- 应用使用 ad-hoc 签名、启用 Hardened Runtime，尚无 Apple Developer 证书或 Apple 公证。
- 已有 iPhone 用户需手动替换或重新导入仓库 `mobile/CodexQuotaWidget.js`；保存的 Scriptable 脚本不会随 Mac 更新自动升级。
- 系统配置备份留在本机，可能包含其他配置，请勿上传或公开分享。

## English

### New: Default Model…

- Select the default model and supported reasoning effort for future chats directly from the menu bar, using the live local Codex catalog.
- Inspect effective backend defaults and distinguish user settings from system/managed overrides.
- **Save and Verify** updates user settings and reads them back with a fresh backend. Local system edits require macOS administrator authentication, preserve unrelated fields, and back up the original file.
- Unsupported formats, active profiles, and unidentified managed sources are refused. Cancellation, partial-save errors, and verification mismatches receive explicit feedback.
- Chinese and English UI. Existing chats, daily schedules, and the dedicated activation model stay unchanged. Restart Codex after running tasks finish if desktop defaults remain cached.

### Background Activation Fixes

- Resolve the CLI on each run, including newer nested desktop-app paths, rather than relying on a stale executable location.
- Check structured turn completion, positive output, and two quota reads instead of treating process exit as proof of activation.
- Wait for a near-expiry window and perform one bounded retry for transient failures. Redacted per-run diagnostics distinguish activation, an existing active window, and unverified results.
- Stop deleting legacy automation files as a substitute for cancellation. Pause old CodexQuotaMenu automations in Codex itself; the app preserves paused records and detects conflicts.

### iPhone Widget Recovery

- Keep the loaded access token in process memory to reduce false 401 responses when Keychain is temporarily inaccessible; return 503 when authentication material is unavailable.
- Retry phone-service startup and recovery after wake/session activation while preserving the user's enabled setting.
- Scriptable retries transient 401/503 once and falls back to a still-valid cache. Real-time data remains unavailable while the Mac is off, asleep, or not serving the feed.

### Install and Upgrade

- Apple Silicon (arm64) and Intel (x86_64) archives, each with SHA-256; macOS 14+ required.
- Hardened Runtime and ad-hoc signing; no Apple Developer certificate or notarization.
- Existing iPhone users must replace or re-import `mobile/CodexQuotaWidget.js`; saved Scriptable scripts do not update with the Mac app.
- System-configuration backups remain local and may contain unrelated configuration. Never publish them.
