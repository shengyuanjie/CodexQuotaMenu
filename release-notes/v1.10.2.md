# v1.10.2 — 高重置概率时保留余量 / Keep Usage Visible During High Reset Forecasts

## 中文

- 修复高重置概率提示遮住当前剩余用量的问题。菜单栏现在显示 `Codex  晌81%余3时  周62%冲冲冲  ▶1`，保留短时余量和倒计时，以及每周余量。
- iPhone 锁屏内联小组件同步调整为 `晌99·59分 周99～冲`，使用一个空格和全角“～”，替换每周倒计时并减少文字占宽。100% 仍简写为“满”。
- 保留现有提示触发和结束规则：首次达到或超过 50% 时生效，两组用量进入下一重置周期后恢复普通显示，低于阈值后重新布防。
- 将锁屏脚本语法和自动化测试加入两种 Mac 架构的 CI 检查。

**iPhone 更新方法：**下载本 Release 的 `CodexQuotaWidget.js`，替换或重新导入 Scriptable 中的同名脚本。iOS 不会自动更新已导入的脚本；使用 iCloud 脚本的用户需等待同步后刷新小组件。实际锁屏刷新由 iOS 调度，文字布局仍以真机显示为准。

macOS 14+，Build 44。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Keep remaining usage visible during an active high-probability reset forecast. The menu bar now shows `Codex  5h81% left3h  W62% Go go go  ▶1`, retaining short-window usage and its countdown as well as weekly usage.
- Update the iPhone inline Lock Screen widget to `晌99·59分 周99～冲`, using one space and a full-width wave dash to reduce text width. Full quota remains abbreviated as “满”.
- Preserve the existing forecast-cycle rules: activate at 50% or higher, restore the normal display after both quota windows advance, and rearm after the forecast drops below the threshold.
- Run widget syntax and automated checks in both Mac architecture CI builds.

**iPhone update:** download `CodexQuotaWidget.js` from this Release and replace or reimport the same-named script in Scriptable. iOS does not automatically update imported scripts. iCloud script users should wait for synchronization before refreshing. Lock Screen refresh scheduling and final text layout remain controlled by iOS.

macOS 14+, Build 44. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
