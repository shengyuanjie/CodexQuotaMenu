# v1.10.7 — 修复已中断任务的运行计数 / Interrupted Task Count Fix

## 中文

- 修复已停止的任务仍显示为运行中、导致菜单栏任务数量偏多的问题。日志中记录回合中断后，任务立即退出运行统计。
- 已中断回合的后续工具输出不会重新触发运行计数；再次发送消息或开始新回合后恢复正常统计。
- 新增中断后工具输出和中断后重新开始的回归测试。

macOS 14+，Build 49。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。无需修改已有设置或更新 iPhone Scriptable 脚本。

## English

- Fixes stopped tasks remaining in the running count. A logged turn interruption now immediately removes the task from running statistics.
- Late tool output from an interrupted turn no longer restores its running state. A new message or turn starts normal counting again.
- Adds regression coverage for late tool output and restarting after interruption.

macOS 14+, Build 49. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization. Existing settings and the iPhone Scriptable widget require no changes.
