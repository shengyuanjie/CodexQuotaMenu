# v1.9.1 — 定时消息窗口显示修复 / Scheduled Message Editor Fixes

## 中文

- 修复消息编辑区首字被裁切的问题，保留约五行的默认高度，并在调整窗口宽度时自动换行。
- 发送时间统一显示为 `yyyy/M/d HH:mm`，例如 `2026/10/2 15:08`，去除单数字日期前的补齐空位。
- 日期时间支持直接编辑，输入无效日期或时间时会提示并阻止安排发送。
- 日期时间与加减按钮置于同一行；四组按钮统一缩小，支持 ±1 分钟、±10 分钟、±1 小时及 ±1 天。
- 保留现有任务、附件、模型与推理强度选择，以及 macOS LaunchAgent 一次性发送逻辑。

macOS 14+，Build 41。同时提供 Apple Silicon（arm64）与 Intel（x86_64）安装包及 SHA-256 校验文件。用户已确认本机窗口显示正常；自动化检查覆盖日期格式、无效日期、中英文最小窗口布局及首字显示。使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Fix clipping of the first character in the message editor. Keep approximately five visible lines and wrap long text when resizing.
- Display the send time consistently as `yyyy/M/d HH:mm`, such as `2026/10/2 15:08`, without padding before single-digit days.
- Allow direct date and time editing; reject invalid input before scheduling.
- Keep the date and compact, consistently sized adjustment buttons on one row, supporting ±1 minute, ±10 minutes, ±1 hour and ±1 day.
- Preserve existing-chat targeting, attachments, model and reasoning selection, and one-time macOS LaunchAgent delivery.

macOS 14+, Build 41. Apple Silicon and Intel archives include SHA-256 files. The user confirmed the local editor display. Automated checks cover date formatting, invalid dates, minimum-width layouts in both languages and first-character visibility. Hardened Runtime with ad-hoc signing, without Apple notarization.
