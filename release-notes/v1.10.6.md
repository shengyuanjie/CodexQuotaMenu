# v1.10.6 — 更新后自动维护激活任务 / Activation Recovery After Updates

## 中文

- 修复应用被替换或重新签名后，已有每日激活任务可能因 macOS 启动约束不匹配而无法运行的问题。
- 启动应用时按主程序内容检查变化，自动重新登记已有激活任务；即使版本号不变，也能识别重新构建的程序。
- 重新登记后通过独立的临时后台任务验证程序能正常启动，不发送模型请求、不消耗激活用量。核验成功后缓存指纹，避免重复登记；失败时可在“激活时间设置”中刷新重试。
- 保留已安装的激活时间，不自动应用尚未同步的设置，不打断正在执行的激活任务。
- 新增可选的本地安装脚本，提供旧版备份、签名与文件校验、后台启动核验及失败恢复。

仍可将 `Codex用量.app` 拖入“应用程序”并双击启动，无需命令行。替换应用后请打开一次新版本，让自动维护完成。升级后不必重新设置激活时间，也无需更新 iPhone Scriptable 脚本。

macOS 14+，Build 48。提供 Apple Silicon（arm64）和 Intel（x86_64）安装包及 SHA-256 校验文件，使用 Hardened Runtime 和 ad-hoc 签名，未经 Apple 公证。

## English

- Fixes daily activation jobs failing macOS launch constraints after the app is replaced or re-signed.
- On launch, detects changes to the executable content and re-registers existing activation jobs, including rebuilds that keep the same version number.
- Verifies background startup with a separate temporary job that sends no model request. Successful verification is cached; failed checks can be retried from Activation Times.
- Preserves installed activation times and unapplied settings, and does not interrupt an activation already running.
- Adds an optional local installer with backup, signature and file checks, background launch verification, and recovery on failure.

Finder installation is still supported: move the app to Applications and open the new version once after replacement. Existing activation times do not need to be entered again. No iPhone Scriptable update is required.

macOS 14+, Build 48. Apple Silicon and Intel archives include SHA-256 files. Hardened Runtime with ad-hoc signing, without Apple notarization.
