# Scriptable 顶部单行小组件设计

## 目标

让 iPhone 锁屏时钟上方的 `accessoryInline` 位置同时显示个人周余量、距离周重置的时间和未来 48 小时全球额外重置概率，并在该位置的单行宽度内保持可读。

正常状态固定采用以下顺序和符号：

```text
◔85% · ⏱︎7天 · ↻23%
```

- `◔` 表示个人周余量。
- `⏱︎` 表示距离个人周重置的时间。
- `↻` 表示 Codex Reset Monitor 的未来 48 小时概率。

## 显示规则

- 仅当 `config.widgetFamily == "accessoryInline"` 时启用紧凑单行布局。
- 周余量显示整数百分比；不可用时显示 `◔--`。
- 重置倒计时只显示最大的有效单位：不少于一天显示整天，不少于一小时显示整小时，否则显示分钟；已到重置时间显示 `⏱︎待重置`，不可用时显示 `⏱︎--`。
- 概率显示 `↻xx%`；预测超过两小时、状态不可用或字段缺失时显示 `↻--`。
- 三段之间使用 ` · ` 分隔，不再显示 `Codex`、`周余量`、`48h` 和`后重置`等长标签。
- 缓存已过期时不展示旧数值，三段均使用不可用占位符。

## 非目标

- 不改变锁屏时钟下方的 `accessoryRectangular` 两行布局。
- 不改变 schema v2、Keychain、缓存、接口鉴权或 Mac 服务。
- 不增加轮播；iOS 对锁屏小组件的实际刷新频率仍由系统决定。

## 实现与验证

- 将紧凑文本生成拆成纯函数，以固定时间测试正常、小时/分钟、已到期和不可用状态。
- `accessoryInline` 只创建一个文本节点，避免第二行被 iOS 丢弃。
- 保留现有 schema v2 测试，并重新执行语法检查和交付副本一致性检查。
- iPhone 最终是否完整显示仍以用户真机锁屏截图为准。
