# Scriptable 刷新概率标签设计

## 目标

将 iPhone Scriptable 锁屏小组件中未来 48 小时全球额外重置概率的标签从 `Tibo` 改为更简洁的中文 `刷`。

正常显示固定为：

```text
剩82% 余6天 刷23%
```

数据不可用时显示：

```text
剩-- 余-- 刷--
```

## 范围

- 修改 `accessoryInline` 锁屏文本生成结果。
- 修改点击刷新成功或缓存兜底提示中复用的同一段摘要。
- 修改对应自动化测试和手机端当前说明。
- 保留现有空格、顺序、字体、单行布局和缩放规则。

## 非目标

- 不修改 Mac 菜单栏文案、接口字段、schema v2、预测来源或概率含义。
- 不修改五分钟最早刷新申请、点击刷新、缓存或诊断日志逻辑。
- 不批量改写历史设计文档中用于描述人物或旧方案的 `Tibo`。

## 验证

- 纯函数测试覆盖正常、小时、分钟、待重置和不可用状态，全部期待 `刷` 标签。
- 点击刷新成功和缓存兜底提示测试同步期待 `刷` 标签。
- 单行渲染测试确认只有一个文本节点，内容为 `剩85% 余7天 刷23%`。
- 运行 JavaScript 行为测试、语法检查及差异检查。
- 将通过验证的脚本同步到交付目录和 Scriptable iCloud Documents，并核对三份文件字节一致。
- 最终锁屏效果由用户在 iPhone 真机确认。
