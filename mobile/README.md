# Codex 余量锁屏小组件（Scriptable）

这个脚本从 Mac 上的 `Codex 用量` 菜单栏应用读取周余量、恢复倒计时和全局额外重置预测。手机不会直接访问预测网站，也不会读取任务标题、路径或对话内容。

## 配置

1. 在 iPhone 安装并打开 Scriptable。
2. 将 `CodexQuotaWidget.js` 导入 Scriptable。
3. 在 Mac 菜单栏展开 `Codex 用量 → 手机小组件`，勾选“启用只读接口”。
4. 依次选择“复制小组件地址”和“复制访问令牌”，把两项安全地传到 iPhone；不要把令牌发到群聊或公开位置。
5. 在 Scriptable 中前台运行脚本，填入地址和令牌，选择“保存并测试”。成功后会显示锁屏横向小组件预览。
6. 长按 iPhone 锁屏进入自定义，在小组件区域添加 Scriptable，选择横向矩形样式并指定这个脚本。

优先使用固定局域网 IP 或路由器的 DHCP 保留地址，例如 `http://192.168.1.20:47821`。通过 Shadowrocket 回家时，`.local` 主机名可能无法解析，建议继续使用 Mac 的固定局域网 IP。

## 安全边界

- Mac 接口默认关闭，只提供 `GET /v1/widget`，不能控制 Codex 或读取对话。
- 访问令牌分别保存在 macOS Keychain 和 Scriptable Keychain，只通过 `Authorization` 请求头发送，不进入 URL、文件或日志。
- Scriptable 的本地缓存只含余量、运行任务数量和预测汇总，不保存地址或令牌。
- 普通 HTTP 只允许私网 IPv4 或 `.local`；普通公网地址会被脚本拒绝。不要在路由器上做端口映射，也不要把 `47821` 暴露到公网。
- 如果令牌疑似泄露，在 Mac 菜单选择“重新生成访问令牌”，然后在 Scriptable 中重新配置；旧令牌会立即失效。

## 刷新与离线行为

- 脚本向 iOS 建议 15 分钟后刷新，但实际时间由系统决定，不能保证准时或固定周期。
- 实时连接失败时会读取最后一次成功的非敏感缓存。
- 离线缓存超过两小时后，显示“Mac 离线 · 数据已过期”，不继续展示旧余量或旧预测百分比。
- 个人余量和预测独立降级；任一数据暂不可用时，另一项仍可显示。

## 排查

- `401` 或令牌错误：从 Mac 菜单重新复制访问令牌。
- 无法连接：确认 Mac 应用正在运行、只读接口已启用、两台设备在同一局域网，或 Shadowrocket 回家链路能访问 Mac 的局域网 IP。
- 地址变化：为 Mac 配置 DHCP 保留地址，然后在 Scriptable 中前台运行脚本更新地址。
- 没有按 15 分钟刷新：这是 iOS 调度限制，不代表脚本或 Mac 服务故障；前台运行脚本可立即测试。

目前自动化验证只覆盖脚本语法和 Mac 接口；iPhone 局域网、Shadowrocket 与锁屏实际显示需要在真机上完成。
